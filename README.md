# 전주대학교 대동제 및 해커톤 로그 데이터 정보 추출 프로그램

파이썬의 정규표현식(`re` 모듈)과 람다(`lambda`) 표현식을 활용하여, 대동제 및 해커톤 통합 운영 로그 데이터에서 유효한 정보만을 필터링하고 정산 금액을 합산하는 프로그램입니다.

## 주요 추출 기능 및 정규표현식 설계

1. **유효한 이메일 추출**
   - 패턴: `r"[a-zA-Z0-9._+-]+@[a-zA-Z0-9-]+(?:\.[a-zA-Z0-9-]+)+"`
   - `@` 뒤에 도메인명이 반드시 오도록 지정하여 손상된 이메일(`hyunwoo@.ac.kr`)을 제외하고 5건만 추출합니다.

2. **휴대폰 번호 추출**
   - 패턴: `r"\b010[-.\s]\d{4}[-.\s]\d{4}\b"`
   - `010`으로 시작하고 구분자(`-`, `.`, 공백)로 연결된 4자리-4자리 번호만 매치하여 지역번호(`063`) 및 자릿수 미달 번호(`010-123-4567`)를 제외합니다.

3. **본교 재학생 학번과 학과 분리 추출**
   - 패턴: `r"\[(202\d{6})\s*/\s*([^\]]+)\]"`
   - `202`로 시작하는 9자리 학번과 학과명을 그룹핑(`()`)하여 `(학번, 학과)` 튜플 형태로 추출합니다.

4. **GitHub 저장소 URL 및 유효 쿠폰 추출**
   - GitHub 패턴: `r"https?://github\.com/[^\s]+"` (`gitlab.com` 제외)
   - 쿠폰 패턴: `r"\bFEST-2026-[A-Z0-9]{4}\b"` (2025년 만료 쿠폰 제외)

5. **부스별 총 매출액 추출 및 합산**
   - 패턴: `r"매출:\s*(\d{1,3}(?:,\d{3})*원)"`
   - `매출:` 뒤에 오는 금액만 추출하여 카드/현금 내역 및 쿠폰 금액(`5,000원`)을 제외하고, `map`과 `reduce`, `lambda`를 활용해 총합계(`6,290,500원`)를 구합니다.
